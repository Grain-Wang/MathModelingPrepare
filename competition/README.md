# ⛔ 只读目录 —— 绝对基准，严禁修改

本目录存放赛题原文、官方附件数据与评分规则，是整个项目的**唯一绝对基准**。

## 红线规则

- 任何人（含 AI Agent）不得修改、覆盖或删除本目录下任何文件。
- 需要处理数据时，先复制到 `projects/01_data/raw/` 再操作。
- 团队全员以本目录内容为准，冲突时以官方文件为准。

## 结构

- `problem/`  赛题原文（PDF/Word）
- `data/`     官方附件原始数据
- `rules/`    评分规则 / 排版与提交要求

## 落地后

1. 将官方赛题文件放入对应子目录。
2. 运行 `powershell -File scripts/make_readonly.ps1` 设为只读。
