# 工具使用指南

- **Zotero**：文献唯一真相源，安装 Better BibTeX 并开启自动导出到
  `reference/literature/zotero_library.bib`。
- **Overleaf**：在线协作论文，与 `projects/04_paper/` 保持同步。
- **Draw.io**：架构图主力，导出 SVG/PDF 矢量。
- **OriginPro**：出版级图精修，最终图统一放 `projects/03_visualization/figures/`。
- **可视化规范**：学术色板 NPG/AAAS、字号 ≥8pt、标签含单位
  （见 `tools_config.yaml` 的 `viz` 段，脚本自动读取保证风格统一）。

详见各文件内注释。
