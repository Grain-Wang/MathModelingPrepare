# 数学建模论文高质量图表指南

本指南给出一套适用于“华为杯”等研究生数学建模竞赛的八图证据链。八张图不是机械凑数要求；应根据赛题类型删减、替换或合并，但整篇论文至少要形成：

> 建模路线 → 数据可信度 → 变量与机制 → 核心结果 → 误差验证 → 方法比较 → 稳健性 → 场景决策

其中，**图 1、图 3、图 8 固定优先使用新版 [Scientific Illustrator](https://github.com/icebird1998/scientific-illustrator)** 制作，保留可编辑源文件；涉及真实数值、统计误差和高密度数据的图，优先由 Python/MATLAB/R 生成，再用 OriginPro 或矢量软件做有限精修。

## 一、八张推荐图总览

| 编号 | 推荐图 | 主要回答的问题 | 主绘图工具 | 建议文件名 |
|---|---|---|---|---|
| 1 | 专业总体技术路线图 | 全文如何从数据走到结论，各子问题如何衔接？ | **新版 Scientific Illustrator** | `fig1_overall_workflow.pdf` |
| 2 | 数据质量与预处理前后对照图 | 原始数据有什么问题，处理是否合理且可追溯？ | Python/MATLAB/R，必要时 OriginPro 精修 | `fig2_data_quality.pdf` |
| 3 | 关键变量关系或结构图 | 变量、模块、机制和约束之间是什么关系？ | **新版 Scientific Illustrator** | `fig3_variable_structure.pdf` |
| 4 | 直接回答赛题的核心结果图 | 题目最终要求的数值、方案、路径或布局是什么？ | 建模代码、GIS 或专业求解软件 | `fig4_primary_result.pdf` |
| 5 | 预测—真实值与残差联合图 | 模型是否准确，误差是否存在系统性结构？ | Python/MATLAB/R | `fig5_prediction_residuals.pdf` |
| 6 | 基线与消融比较图（带误差棒） | 复杂方法是否优于简单方法，关键模块是否必要？ | Python/MATLAB/R，必要时 OriginPro 精修 | `fig6_baseline_ablation.pdf` |
| 7 | 灵敏度或鲁棒性图 | 参数、噪声、约束和场景变化后，结论是否仍成立？ | Python/MATLAB/R | `fig7_sensitivity_robustness.pdf` |
| 8 | 与实际场景对应的最终决策图 | 模型结论如何转化为可执行的现实方案？ | **新版 Scientific Illustrator**；地图底图可由 GIS/Python 生成 | `fig8_decision_scenario.pdf` |

最终编号可以随论文结构调整，但源文件和导出文件应使用同一基础文件名。建议统一保存到：

```text

├── figures/      # 插入论文的 PDF/SVG/PNG
├── sources/      # .drawio、.pptx、.ai、.opju 等可编辑源文件
└── data/         # 每张图对应的最终绘图数据，不存手工编造点
```

## 二、八张图的具体要求

## 图 1：专业总体技术路线图

### 目的

让评委在几十秒内看懂：题目输入是什么、各子问题解决什么、采用什么模型、结果如何传递、怎样验证、最终输出什么。

### 必须包含

- 原始数据、题目附件或业务输入；
- 数据检查、清洗和特征构造；
- 问题一、问题二、问题三之间的依赖关系；
- 每个子问题的主模型或算法，不只写“建立模型”；
- 关键中间产物及其流向；
- 验证、灵敏度分析或失败回退路径；
- 最终交付结果，如预测、评价、优化方案或决策建议。

### 版式建议

- 优先使用从左到右的单一阅读路径；复杂题可使用“上层总流程 + 下层子问题模块”；
- 层级不超过三级，避免把论文目录直接画成流程图；
- 数据、模型、验证、结果使用固定语义配色；
- 箭头表示真实的数据或逻辑依赖，不用装饰性箭头；
- 在框内写“方法 + 产物”，如“孤立森林检测异常值 → 清洗数据集”，不要只写“数据预处理”。

### 工具与交付

使用新版 Scientific Illustrator 在 draw.io 中制作，至少交付：

```text
projects/03_visualization/sources/fig1_overall_workflow.drawio
projects/03_visualization/figures/fig1_overall_workflow.pdf
projects/03_visualization/figures/fig1_overall_workflow.png
```

可复制给 Codex 的提示词：

```text
[@scientific-illustrator](plugin://scientific-illustrator@scientific-illustrator-tools)
使用新版 Scientific Illustrator，在实时 draw.io 画布中设计一张数学建模论文总体技术路线图。
根据我提供的题目分析和模型方案，先提炼“数据输入—预处理—各子问题模型—验证—最终输出”的唯一主阅读路径，
再规划分区、节点、连接线和语义配色。所有文字、形状、箭头、图例和分区必须可编辑；
不得把整图做成位图，不得先生成 XML。逐区域绘制并检查是否存在重叠、裁切、错误连线或阅读顺序歧义。
完成后保存为 fig1_overall_workflow.drawio，并导出矢量 PDF 和宽度 2000 px 的 PNG。
```

## 图 2：数据质量与预处理前后对照图

### 目的

证明数据处理有明确依据，并让评委看到处理前后的变化，而不是只看到“清洗后的漂亮数据”。

### 推荐组成

根据数据类型选择二至四个面板：

- `(a)` 缺失值数量、缺失比例或缺失位置；
- `(b)` 异常点、离群点或重复样本；
- `(c)` 原始数据与清洗后数据的同尺度对照；
- `(d)` 处理前后分布、样本量或关键统计量变化。

时间序列可使用“原始曲线 + 异常点标记 + 清洗后曲线”；表格数据可使用缺失矩阵、箱线图和分布图；空间数据可使用清洗前后轨迹或地图对照。

### 必须标注

- 原始样本数、删除或修复数量、最终样本数；
- 缺失率、异常率或重复率；
- 横纵轴名称和单位；
- 异常判定或插值方法；
- 处理前后使用相同坐标范围，避免视觉夸大；
- 被删除、插值或修复的区域。

### 工具要求

真实数据图由 Python/MATLAB/R 直接读取最终数据文件生成，禁止在 draw.io 中手工摆放数据点。Scientific Illustrator 只可用于最后的面板组织、箭头和解释框，不能代替数据绘图程序。

## 图 3：关键变量关系或结构图

### 目的

把正文中的变量、模块、因果假设、约束和信息流压缩成一张清晰结构图，解释“为什么这样建模”。

### 适用形式

- 输入变量—状态变量—输出变量关系；
- 指标体系或层次分析结构；
- 结构方程路径、贝叶斯网络或因果假设图；
- 供应链、通信、交通、能源等节点—边网络；
- 模型内部模块和串联计算关系；
- 目标函数、约束和决策变量之间的作用结构。

若需要展示的是相关系数热力图、散点矩阵、SHAP 分布或联合密度，应由 Python/MATLAB/R 生成；Scientific Illustrator 负责的是**结构关系图**，不能用主观箭头冒充由数据识别出的因果关系。

### 必须包含

- 节点或变量的准确名称和必要符号；
- 不同箭头含义的图例，如作用、抑制、反馈、信息流；
- 外生变量、决策变量、状态变量和结果变量的分组；
- 与正文公式一致的方向和连接；
- 对尚未由数据证明的关系明确标为“假设关系”或“待验证关系”。

### 工具与交付

使用新版 Scientific Illustrator 制作，保留 `.drawio` 源文件，并导出矢量 PDF。

可复制给 Codex的提示词：

```text
[@scientific-illustrator](plugin://scientific-illustrator@scientific-illustrator-tools)
使用新版 Scientific Illustrator，在实时 draw.io 中设计数学建模论文的关键变量关系/模型结构图。
严格依据我提供的变量表、数学公式和模型接口，先区分输入变量、决策变量、状态变量、约束和输出，
再规划分组、层级和连接线。不得自行增加因果关系；假设关系必须使用与已验证关系不同的线型并配图例。
所有节点、文字、箭头和图例保持可编辑，避免交叉连线和含义不明的装饰元素。
完成后保存为 fig3_variable_structure.drawio，并导出矢量 PDF 和宽度 2000 px 的 PNG。
```

## 图 4：直接回答赛题的核心结果图

### 目的

用一张图直接回答赛题，而不是只说明模型性能。评委应能从图中读出最终数值、方案、路径、布局、排序或时空分布。

### 按题型选择

| 赛题类型 | 推荐核心结果图 |
|---|---|
| 预测与时间序列 | 实际值、预测值、预测区间和关键事件 |
| 路径规划 | 地图上的最优路线、访问顺序、成本或风险 |
| 生产调度 | 甘特图、设备—时间热力图、冲突和空闲区间 |
| 选址与覆盖 | 候选点、最终选址、服务半径和需求覆盖 |
| 网络优化 | 节点、边、容量、流量和瓶颈 |
| 多目标优化 | Pareto 前沿以及最终推荐解的位置 |
| 空间环境与气象 | 预测地图、差值地图或时空演化图 |
| 综合评价 | 对象排序、分层结果和关键指标贡献 |

### 必须包含

- 最终推荐解或关键结果的显式标记；
- 与基准方案或原方案的对照；
- 目标值、成本、收益、误差或覆盖率等核心数值；
- 关键约束是否满足；
- 单位、图例和必要的编号；
- 正文可逐项引用的结果编号或区域名称。

不要把“训练损失下降”或“模型精度较高”当作核心结果图，除非赛题本身只要求模型性能。

## 图 5：预测—真实值与残差联合图

### 目的

同时回答模型是否准确、是否有系统偏差、在哪些区间失败以及误差是否稳定。

### 推荐三面板

- `(a)` 真实值与预测值随时间或样本顺序的对照，可增加预测区间；
- `(b)` 预测值—真实值散点图，增加 `y=x` 参考线；
- `(c)` 残差—预测值或残差—时间图，增加零残差线。

根据任务还可增加残差分布、Q-Q 图、误差累计分布或分组误差箱线图。

### 必须标注

- 明确写出训练集、验证集或独立测试集；
- 样本数及数据时间范围；
- MAE、RMSE、MAPE、R² 等与赛题匹配的指标；
- 零误差线和 `y=x` 参考线；
- 置信区间或预测区间的计算口径；
- 重大异常样本或失效区间。

若赛题不是监督预测任务，可将本图替换为“理论值—仿真值与残差”“回测结果与误差”“约束残差与可行性检查”，不要强行绘制没有真实标签的预测—真实图。

## 图 6：基线与消融比较图（带误差棒）

### 目的

证明所选方法相对于简单方案确有价值，并说明性能提升来自哪些关键步骤，而不是来自一次偶然运行。

### 推荐比较对象

- 最简单且合理的规则或统计基线；
- 常用标准模型；
- 本文完整模型；
- 删除关键模块或约束后的消融模型；
- 必要时加入原方案、官方方案或业务现状。

### 必须包含

- 多次随机划分、交叉验证、Bootstrap 或多场景运行的均值；
- 标准差、标准误或 95% 置信区间，并在图注中说明误差棒含义；
- 样本数、重复次数和数据划分方式；
- 指标方向，如“越低越好”或“越高越好”；
- 相对提升百分比；
- 指标量纲差异过大时使用分面图，避免滥用双纵轴或雷达图。

统计结果由代码自动读取实验汇总文件生成。禁止只画一次运行结果的柱状图，也不要在没有重复实验时伪造误差棒。

## 图 7：灵敏度或鲁棒性图

### 目的

检验参数、输入噪声、场景和约束变化时，主要结论是否保持稳定，并说明推荐方案的适用边界。

### 推荐扰动

- 关键超参数或权重系数；
- 数据噪声、缺失比例或测量误差；
- 需求量、价格、容量、预算或资源上限；
- 初始条件、随机种子或时间窗口；
- 极端场景、设备故障或分布变化。

### 推荐形式

- 单参数性能曲线；
- 双参数热力图或等高线；
- 不同场景的箱线图或误差分布；
- Pareto 前沿；
- 收敛曲线；
- Monte Carlo 结果分布。

### 必须包含

- 基准参数或论文采用参数的位置；
- 合理扰动区间及其依据；
- 可行区间、稳定区间或阈值；
- 结论发生反转或约束失效的位置；
- 每个扰动水平的重复次数；
- 不重新调参的鲁棒性结果与重新调参后的最优结果要明确区分。

不要只展示对方法有利的狭窄参数区间，也不要仅凭一条平滑曲线声称模型“非常稳定”。

## 图 8：与实际场景对应的最终决策图

### 目的

将数学结果转化为可执行、可解释的现实方案，是论文从“算出答案”走向“解决问题”的最后一步。

### 适用形式

- 物流、巡检或交通路线及其执行顺序；
- 生产调度、人员排班和工序流程；
- 供应链、通信、电网或能源网络决策；
- 场站、仓库、医院或服务设施选址；
- 风险分级和应急处置流程；
- 设备、芯片、工厂或资源布局；
- 政策情景下的阶段性实施路线图。

### 必须包含

- 推荐方案及备选方案；
- 执行顺序、时间、节点或区域；
- 关键成本、收益、风险或资源占用；
- 约束和现实边界；
- 从模型输出到实际行动的映射；
- 图注能够概括“为什么推荐该方案”。

若包含真实地图、遥感影像、气象栅格或复杂空间底图，先用 GIS/Python 生成准确底图，再由 Scientific Illustrator 添加可编辑的节点、路线、标注、图例和决策说明。不可用手绘示意图冒充精确地理位置。

### 工具与交付

使用新版 Scientific Illustrator 制作可编辑场景层；如有底图，只允许把不可矢量重建的最小区域作为图片插入，其余文字、路线、箭头、边框和图例均保持可编辑。

## 四、统一视觉与导出规范

### 统一视觉

- 全文同一对象或模型保持同一颜色；
- 主色不超过三种，其余使用中性灰；
- 不依赖红绿差异传递唯一信息；
- 正文字号按论文版面缩放后不低于 8 pt；
- 同类图统一线宽、标记大小、图例位置和坐标格式；
- 多面板统一使用 `(a)(b)(c)`，面板顺序与正文叙述一致；
- 坐标轴必须有变量名和单位；
- 最优点、基准线、阈值和可行区间要直接标注；
- 图注应写出主要发现，而不只是重复图名。

### 导出格式

- 流程图、结构图、折线图、散点图和柱状图优先导出 PDF/SVG；
- 位图至少 300 dpi，预览图宽度建议不低于 2000 px；
- 插入论文前在 100% 缩放下检查文字、图例和线条；
- 避免截图、三维柱状图、三维饼图、彩虹色热力图、词云和无误差棒的模型排名图；
- 数据更新后必须重新运行绘图脚本，禁止手工移动数据点来“美化”结果。
