# 模型合同

模型合同不是分析前的猜测。它应在完整读题和检查附件后形成，同时写入
`projects/02_modeling/题目分析报告.md` 的人工可读章节和
`projects/02_modeling/model-contract.json` 的结构化合同。

## 内容

| 项目 | 必须回答的问题 |
|---|---|
| 任务定义 | 每个子问题要求计算、预测、评价还是决策什么？ |
| 数据 | 输入字段、单位、范围、质量和只读文件是什么？ |
| 结论类型 | 理解题目后，最终需要给出哪类结论和指标？ |
| 模型 | 每个子问题的最小充分模型集合是什么？每个模型承担什么不可替代的角色？ |
| 数学定义 | 变量、参数、目标函数、约束、假设和边界条件是什么？ |
| 实现 | 输入输出、算法步骤、停止条件和依赖是什么？ |
| 验证 | 用什么真实数据、误差、稳定性或对照检验结果？ |
| 风险 | 哪些条件不满足时必须回退或更换方案？ |

数据判定标准必须注明题目、官方规则、文献或数据分析依据。
