# 2024 C 题无损数据预处理

本阶段只建立官方附件的可追溯副本和质量审计，不对样本作删除、插补、平滑、缩放、类别编码、特征筛选或训练集划分。所有输出都是待参赛队员复核的派生产物。

## 输入约束

- 官方题面和附件由参赛队员放入仓库根目录的 `competition/`，管线只读访问。
- `competition/data/` 中的官方附件仅在本机保存，由 `.gitignore` 排除并设置 Windows 只读属性；`.gitkeep` 仍由 Git 跟踪。
- 四个 Excel 文件名须分别包含“附件一/1”“附件二/2”“附件三/3”“附件四/4”；每个角色必须唯一匹配。
- 官方题面已确认每行包含一个周期内等间距采样的 1024 个磁通密度点，因此 `config/preprocess.json` 中 `expected_waveform_points` 固定为 `1024`。
- 训练数据的材料字段若不在列中，只允许从“材料1/一”至“材料4/四”形式的工作表名称推断，并在清单中记录推断来源。

## 运行

先按仓库 `environment.yml` 创建或更新 `math_modeling` 环境，然后在本练习目录运行：

```powershell
conda run -n math_modeling python src/preprocess.py
```

如暂时不需要审计图，可运行：

```powershell
conda run -n math_modeling python src/preprocess.py --skip-figures
```

运行前会检查四个附件是否唯一、输入是否位于 `competition/`，以及 Parquet/Excel/绘图依赖是否齐全。缺少附件或存在歧义时直接停止，不生成虚拟正式数据。

## 产物与解释

- `data/cache/source_manifest.json`：源文件 SHA-256、大小、工作表、字段映射和波形列顺序。
- `data/processed/attachment*.parquet`：三个附件的规范化数据；原始行号、附件、工作表和类别原文均保留。
- `data/processed/base_features.parquet`：同时保留多种峰值定义及最小值、最大值、均值、标准差、RMS、极值位置和波形哈希，不预先选择模型口径。
- `outputs/tables/`：逐样本质量标记、标记汇总、类别计数、无法解析的原始单元格、提交模板映射和序号对齐情况。
- `outputs/figures/`：未经对数变换的分布、固定抽样波形和质量标记概览。
- `outputs/metrics/preprocess_receipt.json`：输入/输出哈希、行数、质量标记数量以及恒为 0 的删除行数。

`quality_flags` 仅表示“需要检查”，不等于该样本应删除。`waveform_overlap_across_attachments` 用于提醒未来划分时防止数据泄漏；它不会改变任何附件内容。

## 测试

测试使用合成内存表格，不冒充官方数据，也不写入 `competition/`：

```powershell
conda run -n math_modeling python -m unittest discover -s tests -v
```

当外部理论标准返回后，再据其口径决定异常处理、信号变换、特征选择和训练/验证划分。
