# 2024 C题：磁芯损耗建模——理论好结果标准

> 用途：作为 `projects/practice/2024_C题_磁芯损耗建模` 的练习验收标尺。
>
> 本标准不是“官方唯一答案”，而是根据仓库中 2024 年 C 题 4 篇获奖论文横向归纳出的 **优秀结果区间、稳定结论与应达到的模型质量**。训练时应优先比较“指标区间 + 结论方向 + 泛化能力”，不要机械追求与某一篇论文完全相同的数值。

---

## 0. 总结：这道题做到什么程度可以认为结果很好？

若希望把一次练习做到接近优秀获奖论文的结果水平，可把下面作为核心验收线：

| 问题 | 优秀结果核心标尺 | 建议练习目标 |
|---|---|---|
| 问题1：励磁波形分类 | 无噪声数据上分类准确率接近/达到 100% | **Accuracy ≥ 99%，目标 100%**；最好同时给混淆矩阵、交叉验证与抗噪测试 |
| 问题2：温度修正 Steinmetz | 修正后 `R²` 约 0.986～0.996；优秀论文集中在约 0.995；相对误差约 13%～16% 可达到优秀论文水平 | **R² ≥ 0.99，优秀目标 ≥ 0.995；MAPE/平均相对误差 ≤ 15%左右**；必须显著优于原始 SE |
| 问题3：因素影响 | 温度、励磁波形、材料均显著；波形、材料通常影响尤其显著；低损耗区域高度集中于正弦波、材料4、较高温度 | 结论应稳定落在 **正弦波 + 材料4 + 70/90℃** 附近，并证明主效应和交互效应 |
| 问题4：跨材料跨工况预测 | 获奖论文最好结果约 `R²≈0.998`，平均相对误差约 `2%～3.5%` | **平均相对误差 ≤ 5% 为合格优秀，≤3.5% 很好，≈2% 属于非常强；R² ≥ 0.995，目标 ≈0.998** |
| 问题5：双目标优化 | 不存在唯一绝对最优数值；优秀论文共同特征是给出 Pareto/权衡关系并验证稳定性 | 必须同时优化“损耗小”和“传输磁能大”，给 Pareto 前沿/多算法对比；解通常偏向 **正弦波、90℃**，材料和频率/Bm 随权重变化 |

**一句话判断：**

> 如果最终方案能做到：问题1约 100% 分类准确率；问题2修正方程 `R²≈0.995` 且相对误差约 15% 或更低；问题4通用模型平均相对误差进入 2%～3.5% 或 `R²≈0.998`；问题3得到正弦波+材料4+70/90℃这一稳定低损耗区域；问题5给出有解释的 Pareto 最优解与稳健性验证，则结果层面已经非常接近 2024 C 题优秀获奖论文水平。

# 1. 问题一：励磁波形分类

## 1.1 获奖论文呈现出的上限

四篇优秀论文中，多篇模型在无噪条件下可以达到 **100% 分类准确率**。因此这道题的问题一并不是一个需要接受 90% 左右准确率的困难分类任务；数据本身具有较强可分性。

典型有效特征包括：

- 峰度、偏度、方差、信息熵等统计特征；
- 峰值/峰峰值；
- 上升、下降速率；
- FFT 主频及幅值；
- 时域 + 频域/时频域组合特征；
- 波形几何形状特征。

典型模型包括：SVM、随机森林、决策树、逻辑回归、MLP、集成投票等。

## 1.2 理论好结果标准

### S档（接近优秀论文强结果）

- Accuracy：**100% 或极接近 100%**；
- Macro-F1：建议 **≥0.99**；
- 三类混淆矩阵几乎无误判；
- K 折交叉验证均值仍接近 100%；
- 加噪声后性能下降可被量化，并能通过更鲁棒的时频域特征减小下降幅度。

### A档（可以接受的竞赛结果）

- Accuracy：**≥98%**；
- 各类别 Recall 均较高；
- 有特征解释和混淆矩阵。

### 需要警惕

- Accuracy <95%：大概率不是题目本身难，而是特征提取、归一化、数据划分或标签处理存在问题。
- 只报训练集准确率 100% 而没有验证集/交叉验证，没有说服力。

## 1.3 可作为 sanity check 的附件二类别数

一篇优秀论文给出的附件二预测结果为：

- 正弦波：20 个；
- 三角波：44 个；
- 梯形波：16 个。

该结果可作为调试时的一个参考锚点，但 **不应把它当作唯一真值来反向调参**。若模型结果差异很大，应首先检查特征和分类边界。

# 2. 问题二：考虑温度的 Steinmetz 方程修正

## 2.1 获奖论文实际达到的水平

获奖论文的代表结果包括：

- 修正模型 `MAPE = 15.94%`，`R² = 0.9954`；
- 另一篇由原始 `R² = 0.929979` 提升至 `0.985661`，误差约降低近 4 倍；
- 三次温度修正模型达到 `R² = 0.9955`，原模型约 `0.9448`；
- 深度自表示温度修正模型相对误差由原 SE 的约 `0.36` 降到约 `0.13`。

由此可以判断：

> **原始 Steinmetz 方程只作为 baseline；一个真正好的问题二结果必须明显优于它。**

## 2.2 推荐验收标准

### S档

- `R² ≥ 0.995`；
- MAPE / 平均相对误差 **≤15%**，如果能进入 10% 左右更强；
- 相比原始 SE 的误差显著降低；
- 残差不再表现出明显温度相关趋势；
- 参数有物理意义，没有为了拟合而出现明显异常参数。

### A档

- `R² ≥ 0.99`；
- 相对误差 ≤20%；
- 比原始 SE 有稳定且显著的提升。

### 不足

- `R² < 0.98` 或修正前后提升极小；
- 只增加高次多项式得到高拟合度，却没有验证集/残差分析；
- 训练集很好、测试/留出温度上明显崩溃。

## 2.3 最重要的论文表达

不要只写“R² 很高”，而应明确给出：

1. 原始 SE；
2. 一种简单温度修正；
3. 最终修正模型；
4. 每个模型的 R²、MAPE/RMSE；
5. 残差图或预测-真实值图。

理想表述类似：

> 原始 SE 的 R² 约为 0.94，加入温度修正后提升至约 0.995，同时平均相对误差下降至约 15% 或更低，说明温度项解释了原模型中主要的系统性偏差。

# 3. 问题三：温度、励磁波形、材料的影响及最优组合

## 3.1 四篇论文共同呈现出的稳定结论

虽然具体统计方法不同，但结论高度一致：

- 温度对损耗存在显著影响；
- 励磁波形对损耗存在显著影响；
- 磁芯材料对损耗存在显著影响；
- 两两交互效应也不能完全忽略；
- **正弦波通常是最低损耗波形；**
- **材料4反复出现在最低损耗组合中；**
- 温度最优点主要集中于 **70℃或90℃**。

代表性结果：

- 90℃ + 正弦波 + 材料4；
- 低频：90℃ + 正弦波 + 材料4；高频：70℃ + 正弦波 + 材料4；
- 70℃ + 正弦波 + 材料4，以及 90℃ + 正弦波 + 材料2/4 均属于统计上很优的组合。

因此不能把“到底是70℃还是90℃”当成唯一正确答案。频率分层、抽样方式和优化准则不同会导致最优温度略有不同。

## 3.2 推荐验收标准

好的答案至少满足：

- 单因素显著性检验完整；
- 至少分析两两交互；
- 对损耗长尾分布做 log 变换或采用稳健/非参数方法；
- 结论不能只来自均值排序，而要配合统计显著性；
- 最低损耗组合应落入 **正弦波 + 材料4 + 70/90℃** 的核心区域，或给出充分证据解释为何不同。

如果最终得到“梯形波 + 材料1 + 25℃最低”之类完全相反结论，应优先排查：

- 是否控制了频率和磁通密度；
- 是否被长尾极端值影响；
- 是否混淆了条件均值与控制变量后的效应；
- 是否直接在全量数据上比较均值而忽略分层。

# 4. 问题四：跨材料、跨温度、跨波形的通用磁芯损耗预测

这是整道题最值得用“硬指标”比较的部分，也是最能拉开论文差距的部分。

## 4.1 获奖论文结果范围

代表性强结果：

- CatBoost + IGSE 先验/模型堆叠：**平均相对误差 0.03542（3.542%）**；
- 特征权重 Bi-LSTM：验证集 **R² = 0.998**；
- 同一模型加噪测试集仍有 **R² = 0.9952**；
- WMTLMSE_DSR：平均相对误差由 0.51 逐步降低至 **0.02（2%）**。

因此，对本题数据来说，通用预测模型做到 10% 左右误差只是“能用”，并不属于获奖论文中的强结果。

## 4.2 理论好结果标准

### S+档（非常强）

- 平均相对误差：**≈2% 或更低**；
- 或 R²：**≈0.998 及以上**；
- 并有跨材料/跨工况、加噪声或独立测试集验证。

### S档（优秀论文水平）

- 平均相对误差：**≤3.5%～4%**；
- `R² ≥ 0.995`；
- 泛化测试没有明显掉点。

### A档

- 平均相对误差：**≤5%**；
- `R² ≥ 0.99`；
- 明显优于物理经验公式 baseline。

### 只算一般

- 相对误差 5%～10%；
- 虽然可用，但距离已公开优秀论文的强结果仍有明显差距。

## 4.3 一个高质量方案应包含的 baseline 梯度

推荐至少比较：

1. 原始/修正 Steinmetz；
2. 普通机器学习模型（RF / XGBoost / GBDT / CatBoost）；
3. 深度模型或增强模型；
4. 最终“数据驱动 + 物理先验/波形特征”的模型。

优秀论文已经表明：**单纯把五个基本变量喂给模型通常不是终点；加入波形形状特征、dB/dt、IGSE/MSE 等物理先验，有机会进一步改善精度和解释性。**

## 4.4 防止虚高指标

因为磁芯损耗跨度很大，必须特别防止数据泄漏和“随机切分虚高”：

- 划分训练/验证/测试集后再做标准化；
- 同一类高度相似波形不要泄漏到两侧；
- 最好增加按材料留一、按工况留一或 OOD 测试；
- 同时报 R² 与相对误差，不只报一个指标；
- 对 `log(P_loss)` 建模时，最终指标必须回到原始损耗尺度计算。

如果随机划分 R²=0.999，但跨材料测试大幅下降，则不能认为已经达到真正的通用预测水平。

# 5. 问题五：磁芯损耗最小 + 传输磁能最大

## 5.1 为什么不存在唯一“标准最优数字”

此问本质上是双目标优化：

- 最小化磁芯损耗 `P_loss`；
- 最大化传输磁能代理量，通常使用 `f × B_m`。

二者天然冲突，因此不同论文采用：

- 加权和；
- 比值/差值目标；
- NSGA-II；
- MOPSO；
- GA、PSO、GWO 等；

得到的单点最优参数会因归一化方法、权重 λ 和代理模型而变化。

所以，**不能把某篇论文的 `(f, Bm, 材料, 温度)` 当作理论唯一答案。**

## 5.2 获奖论文中的代表解

有论文得到：

- 材料2、正弦波、90℃、`f≈79680 Hz`、`Bm≈0.021 T`；
- 对应损耗约 `426.3647 W/m³`，传输磁能指标约 `1673.28`。

另有论文在另一套目标权重下得到：

- λ=1：约 `f=7862.85`、`Bm=9.6e-3`、材料1、90℃、正弦波；
- λ=10：约 `f=50000`、`Bm=0.199`、材料2、90℃、正弦波。

这些不同结果反而说明：**问题五真正要追求的是可靠的 Pareto 权衡，而不是死磕一个数字。**

## 5.3 理论好结果的判据

### S档

- 有完整 Pareto 前沿；
- 至少两种优化算法交叉验证；
- 重复随机运行后 Pareto 前沿基本稳定；
- 给出若干代表点：低损耗优先、折中、磁能优先；
- 所有解满足变量上下界与离散变量约束；
- 最优解由问题四预测模型重新计算验证；
- 最好再用附近网格/局部搜索验证智能算法不是偶然落入伪最优。

### 结果趋势 sanity check

从获奖论文看，一个高质量折中解通常具有：

- **正弦波**：高度常见；
- **较高温度（尤其90℃）**：多次出现；
- 材料：材料2或材料4较常见，但会随目标权重变化；
- `f` 与 `Bm` 存在明显 trade-off：为了增大 `f×Bm` 不可能同时把损耗压到绝对最低。

若算法声称同时取得“全数据最低损耗 + 全数据最大 fBm”，通常意味着目标定义、归一化或约束有问题。

# 6. 推荐用于本项目的三级验收门槛

## Level 1：完成题目

- 问题1 Accuracy ≥95%；
- 问题2 修正模型明显优于原 SE；
- 问题3 给出主效应结论；
- 问题4 相对误差 <10%；
- 问题5 给出一个可行双目标解。

这只能证明“做完了”，不等于优秀论文。

## Level 2：国奖/优秀论文竞争区

- 问题1 Accuracy ≥99%；
- 问题2 R² ≥0.99、相对误差 ≤20%，并有充分误差分析；
- 问题3 有交互效应、显著性和稳健性；
- 问题4相对误差 ≤5% 或 R²≥0.995；
- 问题5 Pareto + 两种算法验证；
- 图表和结果解释完整。

## Level 3：对标这 4 篇优秀论文的强结果

- **P1：Accuracy ≈100%，并有抗噪/交叉验证；**
- **P2：R²≈0.995，MAPE/平均相对误差≈13%～15%或更低；**
- **P3：稳定识别正弦波+材料4+70/90℃为低损耗核心区域；**
- **P4：平均相对误差≈2%～3.5%，或 R²≈0.998，且有泛化验证；**
- **P5：给出稳定 Pareto 前沿、代表折中点和多算法交叉验证。**

达到这一层以后，再继续把某个随机划分上的 R² 从 0.9980 卷到 0.9990，竞赛收益通常已经很低；更值得投入时间的是解释性、鲁棒性、图表质量、模型链条完整性和论文表达。

# 7. 最终练习评分建议（100分）

| 模块 | 分值 | 核心评价 |
|---|---:|---|
| P1 波形分类 | 10 | 准确率、特征解释、交叉验证、鲁棒性 |
| P2 温度修正 | 15 | 相对原 SE 的提升、R²/MAPE、残差与物理合理性 |
| P3 因素分析 | 15 | 主效应、交互效应、统计显著性、最优组合合理性 |
| P4 通用预测 | 30 | 泛化精度，是整题最重要的数值指标 |
| P5 多目标优化 | 20 | Pareto、约束、稳定性、优化算法验证 |
| 全文一致性与解释 | 10 | 五问是否形成完整逻辑链，而非五个独立算法 |

建议判定：

- **90～100：接近/达到优秀获奖论文结果层面；**
- **80～89：有较强国奖竞争力；**
- **70～79：完成度较高，但关键指标或验证仍弱；**
- **<70：存在明显模型、实验或论证短板。**
