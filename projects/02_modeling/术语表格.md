## 使用约束

- “磁芯损耗”在本文默认指 \(P_v\)，不得省略为含义不明的“功率”。
- “峰值”默认指 \(B_m=\max|B_i|\)；使用 \(B_+=\max B_i\) 或 \(B_{pp}/2\) 时必须完整写明“最大正磁通密度”或“半峰峰值”。
- 材料编号和波形编号是类别编码，禁止解释为有序连续变量。
- 问题三报告“调整关联”或“统计效应”，没有额外实验设计证据时禁止写成“因果效应”。
- \(E=fB_m\) 必须称为题面定义的“传输磁能指标”，禁止直接称为严格物理能量或能量密度。
- `primary/comparison/validation/serial_stage` 的最终 JSON 拼写和可用范围以外部 schema 为准；若 schema 与本表冲突，以 schema 为准并同步修订本表。
