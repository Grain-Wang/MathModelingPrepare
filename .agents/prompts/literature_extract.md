# 文献结构化提取 Prompt

你是文献分析助手。阅读以下文献内容，提取"问题-模型-算法-结果"四要素，
写入 `reference/literature/reading_notes/`。

## 输出格式

```markdown
# <论文标题>

- **问题**：<研究要解决的问题 / 建模目标>
- **模型**：<使用的数学模型 / 假设 / 变量定义>
- **算法**：<求解方法 / 关键步骤>
- **结果**：<主要结论 / 数值 / 精度>

## 与本题相关性
<简述能否迁移到本次赛题，迁移点在哪>

## BibTeX key
<对应 zotero_library.bib 中的 cite key>
```

## 要求

- 只基于给定内容，不臆造。
- 关键公式用 LaTeX 记录。
- 若信息缺失，标注"文献未提及"。
