# 层次分析法 (Analytic Hierarchy Process, AHP)

> **一句话速记**：把主观两两比较转化为权重向量，用一致性检验约束"拍脑袋"的合理性。

## 1. 适用范围与典型场景 (When to use)
- **适用场景**：多指标综合评价中的权重确定（准则层/指标层权重）；方案优选（供应商选择、选址决策、招标评审）；指标缺少客观数据、需依赖专家经验的赛题（如风险评价、政策评估）。
- **不适用场景**：指标数量过多（超过 9 个时两两比较一致性极易崩坏）；已有客观数据且希望避免主观时（改用熵权法/CRITIC）；需在大量方案间精确排序时。

## 2. 核心优势与局限性 (Pros & Cons)
- **优势**：无需原始数据，仅凭判断矩阵即可出权重；一致性检验为权重提供可靠性背书，评委认可度高；结构清晰（目标-准则-方案三层），易写易解释。
- **局限性**：主观性强，不同专家打分结果差异大；两两比较随指标数增多极易不一致，需反复调整；难以处理大规模方案。

## 3. 具体实施方法 (How to implement)
### 3.1 核心步骤 (Standard Workflow)
1. 建立层次结构（目标层、准则层、方案层）。
2. 构造两两比较判断矩阵 $A$（1-9 标度，$a_{ij}$ 表示因素 $i$ 相对 $j$ 的重要程度）。
3. 求权重（特征值法或和积法），并做一致性检验 $CR = CI/RI < 0.1$。
4. （多准则时）计算各层组合权重，得到方案总排序。

### 3.2 核心公式/数学表达 (Mathematical Formulation)
判断矩阵满足 $a_{ij}=1/a_{ji}$，权重为最大特征值对应特征向量：

$$A w = \lambda_{max} w$$

一致性指标与一致性比率：

$$CI = \frac{\lambda_{max} - n}{n-1}, \qquad CR = \frac{CI}{RI}$$

其中 $RI$ 为随机一致性指标（$n=3\to0.58,\ n=4\to0.90,\ n=5\to1.12,\ n=6\to1.24,\ n=7\to1.32,\ n=8\to1.41,\ n=9\to1.45$），$CR<0.1$ 时接受判断矩阵。

### 3.3 Python 实战代码框架 (Code Snippet)
```python
# 推荐库：numpy（手写和积法，无需第三方 AHP 库）
import numpy as np

def ahp_weight(A):
    """和积法求权重。A: 正互反判断矩阵 (n,n)"""
    n = A.shape[0]
    B = A / A.sum(axis=0)        # 按列归一化
    w = B.mean(axis=1)           # 行平均 = 权重向量
    Aw = A @ w
    lam = (Aw / w).mean()        # 最大特征值近似
    RI = {1: 0, 2: 0, 3: 0.58, 4: 0.90, 5: 1.12, 6: 1.24,
          7: 1.32, 8: 1.41, 9: 1.45}[n]
    CI = (lam - n) / (n - 1)
    CR = CI / RI
    return w, lam, CI, CR        # CR < 0.1 才通过

A = np.array([[1, 2, 4],
              [1/2, 1, 3],
              [1/4, 1/3, 1]])
w, lam, CI, CR = ahp_weight(A)
print("权重:", w.round(3), "CR:", round(CR, 3))
```
