# 动态规划 (Dynamic Programming, DP)

> **一句话速记**：把多阶段决策问题拆成"状态+转移"，用最优子结构与状态记录避免重复计算，从小规模递推到大问题。

## 1. 适用范围与典型场景 (When to use)
- **适用场景**：
  - 资源在多阶段（时间/工序）的最优分配：如生产计划、库存管理、资金分期投放。
  - 路径成本最小化：最短路、网格路径、编辑距离、序列对齐等有向无环递推。
  - 背包与组合计数：0-1 背包、最长公共子序列、数字三角形等经典递推模型。
- **不适用场景**：
  - 问题无最优子结构（子问题最优无法组合成整体最优），如一般 TSP、含后效性的决策。
  - 状态空间爆炸（多维状态联合取值过多，即"维数灾难"），需配合状态压缩或近似。
  - 状态转移存在环且难以界定阶段时，递推无从下手。

## 2. 核心优势与局限性 (Pros & Cons)
- **优势**：
  - 把指数级暴力枚举降为多项式时间，效率高、代码简洁。
  - 最优性有严格理论保证（最优性原理），结果精确可证。
  - 状态表本身就是过程记录，可回溯出完整最优策略，便于论文呈现。
- **局限性**：
  - 状态设计是关键且高度依赖经验，状态定不好就做不出来。
  - 状态维度一多内存/时间爆炸，连续状态需离散化引入误差。

## 3. 具体实施方法 (How to implement)
### 3.1 核心步骤 (Standard Workflow)
1. 划阶段：确定决策分几步（时间步/工序/背包中逐个物品）。
2. 定状态：定义 $s_k$（阶段 $k$ 的状态），确保能刻画后续所需全部信息（无后效性）。
3. 写状态转移：$f_k(s_k)$ 表示从状态 $s_k$ 出发的最优值，写出递推式。
4. 定边界并递推：从终止状态（或初始状态）倒推/正推填表，再回溯最优路径。

### 3.2 核心公式/数学表达 (Mathematical Formulation)
Bellman 最优方程（最小化，逆推）：
$$f_k(s_k) = \min_{u_k \in U_k(s_k)} \left\{ v_k(s_k, u_k) + f_{k+1}\big(s_{k+1}\big) \right\}$$
其中 $s_{k+1} = T_k(s_k, u_k)$ 为状态转移，$v_k$ 为单步代价，$f_{n+1}(s_{n+1})$ 为终态边界。

0-1 背包递推（容量 $j$，前 $i$ 件物品）：
$$F(i, j) = \max\big\{ F(i-1, j),\ F(i-1, j-w_i) + p_i \big\}$$

### 3.3 Python 实战代码框架 (Code Snippet)
```python
# 推荐库：numpy（DP 无专用库，手写递推最直观）
import numpy as np

# 0-1 背包：容量 W，重量 w，价值 p，求最大价值
def knapsack(W, w, p):
    n = len(w)
    # F[i][j]: 前 i 件物品、容量 j 的最大价值
    F = np.zeros((n+1, W+1), dtype=int)
    for i in range(1, n+1):
        for j in range(W+1):
            F[i][j] = F[i-1][j]                      # 不选第 i 件
            if j >= w[i-1]:
                F[i][j] = max(F[i][j], F[i-1][j-w[i-1]] + p[i-1])  # 选第 i 件
    return F[n][W]

W = 10
print(knapsack(W, w=[3, 5, 2, 7, 4], p=[10, 15, 8, 20, 12]))

# 最长公共子序列（字符串匹配类赛题常用）
def lcs(a, b):
    m, n = len(a), len(b)
    dp = np.zeros((m+1, n+1), dtype=int)
    for i in range(1, m+1):
        for j in range(1, n+1):
            dp[i][j] = dp[i-1][j-1] + 1 if a[i-1] == b[j-1] else max(dp[i-1][j], dp[i][j-1])
    return dp[m][n]
```
