### **1 问题重述** 

#### **1.1 问题背景** 

脉冲星是高速自转的中子星，具备体积小、密度大等特征。脉冲星的自转产生周期性 的电磁辐射脉冲，被认为是宇宙中最精确的天然时钟。因此，脉冲星被应用于深空航天 器的导航。X 射线脉冲星由于其稳定的周期性信号，成为宇宙导航中的重要信标。我国于 2016 年发射了 X 射线脉冲星导航试验卫星（XPNAV-1）对蟹状星云中的 Crab 脉冲星（PSR B0531+21）进行了观测。 



图 1 脉冲星的“灯塔”模型 

Crab 脉冲星自转周期约为 33 毫秒，辐射的 X 射线光子可被空间探测器探测到。在脉 冲星导航中，观测到的光子到达时间需要转换到太阳系质心的参考系，精确的时延模型是 实现导航的关键。这一过程中会受到几何传播时延、Shapiro 时延、引力红移等多种效应的 干扰。 

此外，脉冲星信号弱且含有大量噪声，信号处理过程中需要对脉冲星星历进行周期折 叠，从而提取有效信号。为了深入研究 X 射线脉冲星的辐射过程，开展脉冲星光子到达时 间的仿真有助于减少实测数据不足的问题。 

#### **1.2 问题提出——X 射线脉冲星光子到达时间建模** 

由于 X 射线信号不能穿过地球大气，因此脉冲星的 X 射线波段观测只能在空间开展。 2016 年 11 月，我国发射了首颗 X 射线脉冲星导航试验卫星（X-ray Pulsar Navigation-1, XPNAV-1）对蟹状星云 Crab 脉冲星（PSR B0531+21）进行观测。Crab 脉冲星位于超新星 1054 AD（Anno Domini，此处指公元 1054 年）中心处，是恒星、超新星爆发后在蟹状星 云中的残骸，自转周期约为 33ms，在 X 射线波段具有很强的流量，辐射的 X 射线光子可 被空间 X 射线探测器探测。 

#### **1.2.1 轨道六根数** 

在进行天体观测时，卫星由于其绕地球的周期性运动，其轨道位置会持续发生改变。 为了在三维空间中精确地定位卫星轨道上的特定点，必须使用六个关键的 **轨道参数** ，这些 参数也被称作轨道根数、轨道要素或轨道参数，具体包括： **偏心率（** _e_ **）、角动量（** _h_ **）、轨** 

5 

**道倾角（** _i_ **）、真近点角（** _θ_ **）、升交点赤经（** Ω **）** 以及 **近地点幅角（** _ω_ **）** 。为了重建脉冲星的周 期性信号，需要将接收到的光子的时间信息转换到一个惯性参考系中的固定点，例如太阳 系质心天球参考系（Barycentric Celestial Reference System，BCRS）的坐标原点，也就是太 阳系的质心（Solar System Barycenter，SSB）。

#### **1.2.2 时延因素** 

X 射线脉冲星导航（XPNAV）与全球定位系统（GPS）的差分定位（DGPS）技术在 原理上具有相似之处，均依赖于信号到达时间的测距方法。DGPS 定位技术通过比较地面 监控站与接收机接收同一卫星信号的时间差来确定接收机的位置和速度。类似地，XPNAV 通过比较太阳系质心和航天器（如卫星）接收同一脉冲星信号的 **时间差** 来实现航天器的定 位和导航。为了实现这一目标，必须分别计算脉冲星信号到达航天器和太阳系质心的时间 差，也被称作 **时间转换方程** ，进而确定航天器相对于太阳系质心的位置。 

脉冲星信号传播过程受多种因素的共同干扰，包括： 

（1） **真空几何传播时延（Roemer 时延）：** 指在理想真空环境中，信号以光速进行传播 所产生的时间延迟。 

（2） **Shapiro 时延：** 指光子在通过强引力场（如太阳引力场）时，由于引力弯曲路径所 产生的额外时间延迟。引力场引起的光线弯曲如图 2 所示。 

（3） **引力红移效应：** 引力红移是广义相对论中的一个重要现象，描述了光或电磁波在 强引力场中传播时频率降低、波长变长的现象。指脉冲星信号在穿越不同引力场区域，如 太阳引力场时，其频率会发生相应的变化。 

（4） **动钟变慢效应：** 动钟变慢是狭义相对论中的一个重要概念，描述了在高速运动状 态下时间膨胀的现象。当卫星以高速在轨道上运动时，其上的时间相对于静止参考系中的 时间会变慢，这种效应在高精度时间测量中具有重要意义。 

（5） **脉冲星自行：** 指脉冲星在天空中相对于其他天体的位置随时间发生变化。

### **5 问题一的模型建立与求解** 

#### **5.1 模型建立** 

在轨道动力学中，卫星的轨迹和速度是通过一组六个关键参数来确定的，这些参数统 称为开普勒轨道元素（Keplerian Elements）。这些元素是描述天体沿开普勒轨道运动时，其 轨道特征的一组基本量度 [1]。 



图 3 轨道六根数示意图 

**偏心率（** _e_ **）** 是描述轨道形状的一个参数，用来量化轨道相对于圆的偏离程度，椭圆轨 道的偏心率越大，其形状就越扁平。 

**角动量（** _h_ **）** 反映了物体绕特定轴或点的旋转动量，是物体质量、速度以及与旋转轴 或点的垂直距离的函数。 

**升交点赤经（** Ω **）** 定义了轨道平面与参考赤道平面相交线在赤道上的投影位置，表示 轨道相对于赤道的取向。 

**轨道倾角（** _i_ **）** 是轨道平面与参考赤道平面之间的夹角，决定了轨道相对于地球赤道的 倾斜程度，对卫星的地面覆盖范围和发射场的选择具有决定性影响。 

**近地点角（** _ω_ **）** 是从轨道平面与参考赤道平面的交点，即升交点，沿轨道平面量度到 轨道上离中心天体最近的点，即近地点的角度，表示轨道在轨道平面内的方向。 

**真近点角（** _θ_ **）** 是从轨道上的近地点到天体当前位置所对应的角度，用来确定天体在 其轨道上的确切位置。

首先，太阳系质心（SSB）并不完全位于太阳中心，而是受到所有太阳系天体质量分 布的影响。尽管地球轨道半径约为 6371.393km，但在特定脉冲星方向下，卫星相对于 SSB 的实际距离可能显著小于 6371.393km。例如，当脉冲星位于太阳与地球连线的反方向时， 卫星可能位于靠近 SSB 的一侧，从而使得光传播时延减少到 277 秒左右。 

其次，文献中关于深空导航系统的研究表明，脉冲星信号的传播时延不仅取决于地球 与 SSB 之间的距离，还与卫星在轨道上的具体位置密切相关。在不同脉冲星方向和卫星轨 道位置下，光传播时延会有显著变化，特别是在远离地球的深空任务中，时延值可能远低 于 1AU 对应的 277 秒。 

此外，轨道力学的分析表明，卫星在不同轨道参数下的位置变化会影响光传播时延。 例如，若 XPNAV-1 卫星处于近地轨道，其相对于 SSB 的额外距离变化较小，但若处于更 远的轨道或进行深空飞行任务，光传播时延相应减少或增加。因此，277 秒的时延可能对 应于卫星在特定深空位置上的几何关系。 

综上所述，277 秒的几何传播时延在考虑脉冲星方向、卫星轨道位置及太阳系质心的 复杂几何关系后，是一个合理且符合预期的结果。

#### **9.1 模型的评价** 

#### **9.1.1 模型优点** 

（1）本文中构建的卫星轨道根数与其位置和速度的关系模型，通过应用开普勒定律和 角动量原理，同时考虑了轨道参数对卫星与中心天体之间距离的影响，提高了对卫星运动 预测的准确性； 

（2）本文中构建的时延模型综合考虑了脉冲星自行、Roemer 时延、Shapiro 时延、引 力红移时延以及狭义相对论的动钟变慢效应，提供了一个全面和精确的时延计算框架，经 验证能够预测和校正由于光速有限性和其他相对论效应引起的信号传播延迟； 

（3）本文中对脉冲轮廓模型的构建，使用泰勒级数展开来描述脉冲星相位随时间的变 化，并通过历元折叠法，能够有效地从观测数据中提取脉冲星的周期性特征，构建出高质 量的脉冲轮廓。 

#### **9.1.2 模型缺点** 

（1）在根据轨道根数对轨道平面建模时，可能在处理高度椭圆形或不规则轨道时的准 确性有所下降，因为不同轨道的复杂度不同； 

（2）在计算脉冲星到卫星距离时，可能没有充分考虑大气扰动或其它外部因素对信号 传播路径的影响； 

（3）尽管模型考虑了多种时延因素，但在实际应用中可能需要更多的实测数据来校准 模型参数，以确保在不同的环境条件下都能保持高度精确。 

#### **9.2 模型的推广**
