# 中国研究生创新实践系列大赛 “华为杯”第二十一届中国研究生 数学建模竞赛 

题 目： <u>高速公路应急车道紧急启用模型</u> 

## 摘 要： 

高速公路拥堵现象的成因复杂多样，除了交通事故，瓶颈现象尤为突出，这通常源 于车辆的集中流动，导致拥堵现象容易扩散。目前，高速公路管理部门在应急车道的使 用上还处于探索阶段，多依赖视频监控和管理者经验判断。这样的做法虽然直观，但缺 乏理论依据，导致效果难以评估。因此，建立数学模型来识别即将发生拥堵的条件，进 行拥堵预警，并评估临时借用应急车道的效果，优化监控点布局，以帮助管理者做出科 学决策，具有重要的理论与现实意义。 

针对问题一，为统计四个观测点的交通流量、车流密度以及时间平均速度三个交通 流参数随时间的变化规律。本问题首先，根据附件提供的视频数据利用 Opencv 模型对 视频数据进行预处理，包括 透视变换 、异常值处理操作；其次，基于 YOLOv8 模型逐帧 从视频数据中提取四个观测点的交通流参数，绘制每个观测点对应视频的交通流参数随 时间的 变化趋势图 ；最后，通过对变化趋势图的分析，确定 交通流参数随时间的变化规 律 。 

为实时预警从第三点到第四点之间路段可能常出现的持续拥堵状态，本问题首先， 根据交通流参数建立 交通流拥堵模型 ，得出交通拥堵指标随时间的变化趋势；其次，在 拥堵模型的基础上，建立 拥堵状态实时预警模型 ；最后，通过基于 时空集成学习的交通 流时序预测 方法，在交通流拥堵模型初步判断拥堵状态的基础上，加入了 窗口梯度判别 机制 ，从而建立了交通拥堵状态实时预警模型，并验证了其预测结果的有效性和准确性。 

针对问题二，为合理启用高速公路应急车道，首先，结合高速公路通行能力，根据 问题一得到的交通流参数，计算 交通流中断概率 ，观察四个观测点对应视频交通流中断 概率随时间变化的情况；其次，为评估发生交通拥堵的概率， 建立了高速公路应急车道 启用模型 。通过分析可得，当车流量较大时，交通拥堵 概率也较大，车流速度下降，更

针对问题三的实时决策问题，确保 车辆在行驶过程中的道路安全是前提条件 。因此， 本问题首先，对车道控制时间与空间变化频次进行约束，设定了 时空安全约束条件 ；其 次，结合问题一的交通拥堵指标和拥堵实时预警模型，问题二的交通流中断概率模型， 设定了启用应急车道的实时决策策略 ，建立了应急车道启用实时决策模型；最后，从 总 行程时间 、 总碰撞暴露时间 、 平均通行时间 、 总延误时间 和 车辆平均速度 这五个指标量 化了该模型对应急车道控制的影响。通过对量化结果的分析可知，所建立的应急车道启 用实时决策模型有效缓解了交通拥堵。 

针对问题四，需要在 科学决策 和 控制成本 的前提下，合理布置第三个点到第四个点 之间路段视频监控点的位置和数量。首先，从 安全性、效率以及成本 三个角度出发，建 立了监测点布置策略多目标优化模型；然后，基于 **Kriging** 元模型 和 遗传算法 ，求解出 对应路段视频监控点的最优位置和数量，从而求得 最佳布置方案 。最后，将算法求解出 的最佳方案布置到观测点 3 和观测点 4 之间的路段中，可以得出，布置后的视频监控相 较于原方案，平均通行时间降低了 22.37%，总延误时间降低了 26.49%，总碰撞暴露时 间降低了 19.12%，总行程时间降低了 16.24%，车辆平均速度提升了 7.23%。

#### 一、 问题背景与问题重述 

###### **1.1** 问题背景 

高速公路拥堵现象的成因复杂多样，除了交通事故，瓶颈现象尤为突出，这通常源 于车辆的集中流动，导致拥堵现象容易扩散。特别是在匝道出入口或桥梁入口等地段， 拥堵现象更为明显。此外，一些高速公路因车道数量不足，通行能力受到限制，也是导 致拥堵的重要因素。尽管拓宽道路可以有效缓解拥堵，但这并不在本研究的考量范围之 内。我们的重点是如何在现有条件下最大化资源利用。在某些特定情况下，若能在拥堵 发生之前采取措施，便可有效化解潜在的交通堵塞。高速公路建设时，通常会在右侧增 设应急车道，以满足工程救险和紧急救援的需求。尽管应急车道通常被视为救生通道， 限制占用，但若能合理使用，比如通过监控系统及时识别潜在拥堵路段，允许在没有事 故的情况下使用应急车道，能有效降低车流密度，避免大规模拥堵。 

目前，高速公路管理部门在应急车道的使用上还处于探索阶段，多依赖视频监控和 管理者经验判断。这样的做法虽然直观，但缺乏理论依据，导致效果难以评估。因此， 建立数学模型来识别即将发生拥堵的条件，进行拥堵预警，并评估临时借用应急车道的 效果，优化监控点布局，以帮助管理者做出科学决策，具有重要的理论与现实意义。 

###### **1.2** 问题重述 

高速公路建设时通常会在右侧增设应急车道，用于应对紧急情况。然而，在非紧急 情况下，合理利用应急车道可以有效缓解拥堵。本文针对某路段（长度约 5000m，行车 道 2+应急车道 1）进行研究，通过四个视频观测点采集数据，建立交通流拥堵模型，探 索实时预警机制，并研究如何通过合理布置视频监控点来提高应急车道临时启用决策的 科学性和成本效益。 

本文需要解决下列四个问题： 

问题一：数据分析和拥堵模型的建立 

(1) 数据分析：根据四个观测点的视频数据，统计每个观测点的交通流参数随时间 的变化规律，包括车流密度、流量、速度等。通过更精细的统计分析，可以揭示交通流 变化的趋势和规律，为模型的建立提供更准确的数据支持。 

(2) 交通流拥堵模型建立：利用四个观测点的交通流参数，结合道路情况（两行车 道），建立交通流拥堵模型。该模型是随着车流密度、流量、速度等参数的变化而变化。 

(3) 交通流拥堵预警模型：根据观测点 3 和观测点 4 的第一个视频所统计的每个观 测点的交通流参数随时间的变化规律，建立交通流参数预测模型，从而预测并基于交通 流拥堵模型判断出从第三点到第四点之间路段可能出现持续拥堵状态，得出实时预警时 间。 

7 

(4) 交通流参数预测模型验证：利用观测点 3 和观测点 4 的第二个视频数据，来验 证根据观测点 3 和观测点 4 的第一个视频所构建的有效性，从而评估模型的准确性和可 靠性。 

问题二：合理高速公路启用应急车道的建立 

(1) 基于问题一中获取的交通流量，车流密度和时间平均速度的结果，得出的交通 拥堵指数进行分析； 

(2) 构建并求解交通流中断概率模型，从而确定高速公路启用应急车道速度与交通 流量的阈值，达到合理启用高速公路应急车道模型。。 

问题三：应急车道启用实时决策模型 

(1) 决策机制: 在确保车辆在行驶过程中的道路安全的前提条件下，根据建立的拥 堵模型，制定应急车道临时启用规则。当模型预警第三点到第四点之间路段可能出现持 续拥堵时，决策系统会根据预警时间、拥堵程度等因素，决定是否启用应急车道。 

(2) 效果评估: 选择如总行程时间、总碰撞暴露时间、平均通行时间、总延误时间和 车辆平均速度等指标，量化评估应急车道启用模型的效果，包括减少拥堵时间、提升通 行效率、降低交通事故风险等方面的效益。 

问题四：监控点布置策略多目标优化模型 

在确保车辆在行驶过程中的道路安全的前提条件下，需考虑以下三点： 

(1) 关键路段:重点关注容易出现拥堵的路段，例如匝道出入口、桥梁入口等。在这 些路段增加监控点，可以更准确地监测交通流量变化，提高预警的准确性和及时性。 (2) 数据覆盖:确保视频监控覆盖整个路段，以便全面掌握交通流信息，为模型提供 更准确的数据支持。 

(3) 成本控制:合理规划监控点位置，避免过度密集，以控制成本，确保资金效益最 大化。

#### 二、 基本假设与符号说明 

###### **2.1** 模型基本假设 

在数学建模的过程中，在不影响模型意义与计算精度的前提下，为了使模型简单、 明确，计算建立了如下假设： 

(1) 数据真实可靠，各个观测点之间的交通流是独立的且互不影响； 

(2) 每个观测点提供的数据能够精确反映车辆的流量、密度和速度，不存在视频数 据丢失和观测误差。 

(3) 假设在没有突发交通事故的情况下，交通流在特定路段内是相对稳定的。即在 相同的交通条件下(如时间、天气、路况等)，交通流的密度、流量和速度之间的关系是 可以预测的。 

(4) 假设在特定条件下(如交通流密度达到一定值时)，临时启用应急车道能够有效 降低车流密度，提高车辆通行速度，从而缓解拥堵现象。

###### （ **2** ）混合特征选择 

特征选择通过删除不相关、冗余或嘈杂的特征，从所提取的与输出变量相关的原始 特征中选择最相关特征的过程。原始高维数据会致使模型计算时间增加、维数灾难和过 拟合等问题，最终导致模型精度的丢失。有效的特征选择是机器学习模型进行预测训练 的关键部分，因此使用有效的特征选择方法从提取的原始特征中选取相关性最高的特征 至关重要。特征选择方法通常分为过滤法、包装法和嵌入法。 

过滤法通常不依赖于模型，仅站在数据的角度进行特征筛选，该方法可细分为两种 类型。第一种类型根据特征所包含的信息量进行评判，例如方差选择法根据特征数据的 方差来衡量特征的有用性。第二种类型根据每个特征与目标特征的相关度进行评判，剔 除相关度低于所设定阈值的特征。特征相关度的计算方式包括 Pearson 相关系数、卡方 验证、互信息和最大信息系数等。过滤法的效率高，过拟合风险小，但是可能会出现特 征冗余，未考虑到特征间的相互作用。不同于过滤法，包装法根据模型训练后在测试集 上的性能来进行特征选择。该方法将数据划分为训练集和测试集，搜索出使得训练后的 

27 

模型在测试集上性能最优的特征子集。最优特征集合的搜索方法包括暴力搜索、贪心搜 索和启发式搜索三种。相较于过滤法，包装法所筛选出的特征均能够提升模型的性能， 但是特征集合搜索过程需要经历大批次的训练，效率低下，仅适用于特征及样本量较少 的场景。嵌入法将特征选择嵌入到模型训练过程中，模型训练结束后即可得到有用特征。 嵌入法同时兼顾了嵌入法和包装法的优点，运行效率适中且过拟合风险较低。 

本文综合考虑各特征选择方法的优缺点，选用过滤法和嵌入法相结合的混合特征选 择方法使用皮尔逊相关系数（PCC，过滤法）及随机森林（RF，嵌入法）进行特征选择。 皮尔逊相关系数被用于度量每个特征与交通流之间的相关程度，该方法的具体计算过程 如公式(12)所示。

> _T_ ˆ _g_ ˆ( _x_ ) = _f_ ( _x_ ) β+ _Z_ ( _x_ ) (52)

遗传算法是一种基于种群的随机优化方法。其主要操作包括交叉、变异和选择三种。 交叉操作模拟了现实世界中父母遗传物质混合的过程，通过这种方式可以产生新的解， 而这些解源于两个优秀的父代解，因此通常优于两个父代。变异操作是遗传算法中一个 关键的算子，尤其在采用位字符串表示解时，常用位随机翻转突变方法。该方法通过设 定突变率，以一定概率翻转 0 或 1。选择操作是遗传算法中的另一重要算子，通过保留 适应度较高的个体作为新一代的父代，加速了解向最优解的收敛。其优势在于基于适应

#### 八、 模型评价 

###### **8.1** 模型的优点 

（1）针对交通流参数的预测和交通预警信息而建立的交通流参数预测模型和交通 预警模型能够同时考虑时间和空间深层特征并进行特征筛选与提取，能够更加准确地预 测出交通流参数以及交通拥堵指数。 

（2）针对交通流拥堵概率而建立的交通流中断概率模型采用最大似然估计法估计 分布参数，能够准确地给出交通流在不同时刻的拥堵概率，从而确定速度和流量阈值。 （3）针对应急车道是否启用的实时决策问题而建立的应急车道启用实时决策模型 同时利用了交通拥堵预警模型、交通流中断概率模型以及时空安全约束模型，在确保安 全的前提下，可以在拥堵发生前一定时间自主决策是否需要开启应急车道。 

（4）针对监控摄像头的合理布置问题，建立了多目标优化函数，同时考虑了效率、 安全、成本的指标，并通过 Kriging 元模型辅助的遗传算法模型进行最优值的求解，平 衡了效率、安全以及成本的权重，从而更加合理地布置监控摄像头。 

###### **8.2** 模型的改进和展望 

（1）在从视频数据中提取交通流参数时，可以考虑提取更多的参数，例如车道容 量、货车与小轿车的比例等问题，以完善建立的模型。 

（2）对于车流参数的计算可以考虑地更为精细一点，例如可以区分每个车道的车 流参数，对每一个车道进行模型的建立分析。 

（3）可以考虑加入更为智能的自动化决策模型，例如利用深度学习技术建立从视 频交通流参数提取到控制应急车道开启的全自动化决策模型。
