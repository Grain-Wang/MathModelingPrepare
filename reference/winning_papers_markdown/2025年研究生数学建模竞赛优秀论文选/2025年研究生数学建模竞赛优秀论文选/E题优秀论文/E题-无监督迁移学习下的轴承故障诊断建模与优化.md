# **中国研究生创新实践系列大赛 “华为杯”第二十二届中国研究生 数学建模竞赛** 

`题 目：` <u>无监督迁移学习下的轴承故障诊断建模与优化</u> 

## `摘 要：` 

轴承作为高速列车走行系统中的关键旋转部件，在复杂工况下容易易损坏，因此发掘 轴承故障信号特征以及进行精准智能故障诊断具有重要意义。迁移学习能够利用台架实验 数据作为源域知识迁移到实际运营环境，有效缓解样本不平衡并提升故障诊断的工程适用 性。 

针对问题一，首先进行数据筛选，从数据集中选取采样率为 48 kHz 的驱动端振动信 号，并重采样至 32 kHz。其次，采用两阶段的 **TVFEMD** 与 **GWO-MOMEDA** 组合进行 降噪处理，随后，进行 **SMOTE** 实现样本平衡。最后，对信号进行切片并进行特征提取， 分别从 时域 、 频域 与 熵域 构建 36 项特征指标，并进一步引入 **MixHop** 实现多域特征融合， 实现对轴承状态信息的综合表征。 

针对问题二，首先在第一问的多域融合特征数据集上进行 归一化与标准化 。接着对数 据集进行 8:2 的随机划分，前者用于算法训练，后者用于验证算法准确率。本文全面评估 了 随机森林 、 长短期记忆网络 、 卷积神经网络 以及 **Vision Transformer** 算法在故障诊断上 的表现，并通过 性能 和 稳定性 分析选择了最优的 Vision Transformer 模型。作为本问及后续 的基础模型，准确率达到了 95.7%。 

针对问题三，首先利用 核密度估计 对源域与目标域的特征分布进行对比，确认两者存 在显著分布偏移。随后，基于最大均值差异与统计特征变换的度量，提出跨数据空间、跨 阶数的 二阶与高阶统计量联合匹配策略 。在此基础上，构建基于 Vision Transformer 的 无 监督领域自适应网络 ，通过二阶与高阶矩的联合对齐缩小源域与目标域的分布差距，并借 助权值共享机制促进可迁移特征的学习，从而实现高效的领域自适应。 

针对问题四，首先通过特征空间的可视化与定量度量，呈现迁移前后由“散乱到对齐” 的 跨域特征演化 ，直观展示对齐效果；其次，从质心—方差对齐与距离分布出发，量化域 级统计对齐程度与残余偏差，并评估其对跨域鲁棒性的贡献；最后，结合 注意力可视化 开 展事后可解释性分析，对单次预测的证据与可信度进行审计，并与 轴承故障机理 进行一致 性验证。 

`关键词：` 轴承故障诊断、TVFEMD 算法、MixHop、SMOTE、高阶与二阶联合

### 1 问题重述 

#### 1.1 问题背景 

随着我国高速铁路技术的快速发展，高速列车正以其安全高效、便捷舒适、绿色低碳 等特点，逐渐成为绝大多数市民出行的首要选择。日均数以百万计的乘客信赖并选择高铁 出行，这不仅体现了其作为现代交通工具的巨大成功，还对列车的可靠性和安全性提出了 很高的要求。然而，在这光鲜的背后，高速列车走行系统中的关键旋转部件——轴承，却 构成了运营安全与效率的一大潜在隐患。 

轴承主要结构为内圈、外圈、滚动体和保持架四部分，其中典型故障多发生在内圈、 外圈和滚动体这三个核心承载部件。轴承作为高速列车走行系统的关键旋转部件，其工作 环境复杂恶劣，长期承受着高转速、交变载荷以及复杂振动冲击等多重挑战。这种严苛的 工况，使得轴承部件可能因过热、润滑不良、腐蚀等多种因素发生损坏，进而影响列车正 常运行。一旦轴承出现故障，其后果将是灾难性的，轻则导致列车在高速运行中发生异响、 振动加剧，影响旅客出行体验及铁路运营效率；重则可能诱发更严重的恶性事故，如车轴 断裂、轮对脱轨等，直接危及乘客的生命安全，造成巨大的经济损失和社会影响。因此， 对高速列车轴承进行实时、精准的状态监测与故障诊断，是确保列车安全、高效运营的重 中之重<sup>[1]</sup> 。 

目前高铁轴承状态的监测方法主要依赖于传统的信号处理技术，结合专家经验构建的 特征指标进行故障诊断。这些方法通常包括振动信号的时域、频域分析，通过提取均方根 值、峰值、峭度、谐波分量等特征来判断轴承的健康状况。在早期，这些方法在一定程度 上发挥了作用，为铁路运输的安全提供了基础保障。然而，随着中国轨道交通系统进入快 速发展时期，列车运行密度持续增加，运营场景日趋复杂，智能化、强耦合度的发展趋势 对轴承故障诊断技术提出了前所未有的高要求。现有传统方法在诊断精度、泛化能力和实 时性方面，难以满足复杂运营场景下对轴承故障进行精准、高效诊断的需求<sup>[2]</sup> 。 

近年来，随着深度学习技术的飞速发展，数据驱动的智能故障诊断方法在工业装备运 维领域，尤其是在列车装备运维领域受到了广泛关注。深度学习模型，以其强大的特征学 习能力和模式识别能力，能够从海量的运营数据中自动提取高维、抽象的故障特征，实现 远超传统方法的故障识别精度。 

然而，将深度学习模型应用于高速列车轴承的实际故障诊断，面临着两项核心挑战： 复杂运行环境对传感器原始信号的影响；真实故障数据的极度稀缺与数据分布严重不平 衡。 

在此背景下，迁移学习技术为解决上述两大难题提供了解决方案。迁移学习作为一种 新兴的机器学习方法，其核心思想是将在一个任务或领域中学到的知识，迁移并应用于另 一个相关但不同的任务或领域，以提升目标任务的模型性能。对于高速列车轴承故障诊断 而言，这意味着可以充分利用数据量丰富、标签完善的台架实验数据（源域）来训练一个 初步的故障诊断模型，然后将该模型学习到的通用故障知识迁移到数据稀缺、分布不平衡 的实际运营列车数据（目标域）上，通过少量的目标域数据进行微调，从而有效缓解真实 故障数据稀缺和样本不平衡的问题，最终实现更高精度、更强泛化能力和更高效的实时诊 断。

### 4 问题 1：基于自适应 MOMEDA 与 MixHop 的多域融合特征矩阵构建 

#### 4.1 问题分析 

根据题目要求，考虑后续目标域的迁移任务，需结合轴承故障特征，对源域数据集进 行数据预处理，选取合适的方法对整体数据集进行特征提取，以及对有代表性的源域数据 进行特征分析。本节对该问题的解答可分为以下步骤： 

（1）数据筛选阶段。源域数据集中包含驱动端和风扇端轴承在 12KHz 和 48KHz 的采 样频率下，4 种工作状态下不同故障尺寸所采集的振动信号数据，我们从中筛选出 48kHz 频率下的驱动端信号。 

（2）数据预处理阶段。首先，进行数据重采样，源域数据集中 DE 的加速度信号从 48kHz 变换为与目标域数据集一致的 32kHz；再使用 TVFEMD 算法，将原始轴承故障振动 信号分解成多个 IMF 分量，选取包含故障信号较多的分量进行累加，完成第一阶段的去噪 操作；再根据第一阶段得到的信号，结合自适应 MOMEDA 算法和灰狼优化算法（Grey Wolf Optimizer,GWO）进行第二阶段的去噪。 

（3）特征提取阶段。主要从时域、频域和熵域三个维度进行信号特征的选择，共选 取了 16 个时域特征指标，13 个频域特征指标和 7 个熵域特征指标。将步骤（1）中得到的 最优 IMF 组合信号等分成多个小样本，并在每个小样本中提取上述的 36 个特征指标，将 其拼接成一个特征矩阵。再基于 MixHop 模型对提取的特征矩阵进行融合优化。

#### 4.2 数据筛选 

为保证源域与目标域之间的特征可比性并最大化保留故障信息，本研究在源域数据中 优先选择 48kHz 采样频率且来自驱动端（DE）的加速度信号。选择依据包括采样频率、 传感器位置、信噪比与故障特征频带四个方面： 

（1）采样频率与频谱信息完整性 

轴承故障产生的冲击会激发高频共振模态，包络解调与谱峭度等诊断指标往往依赖于 高频率信号特征。48kHz 的采样频率能覆盖比 12kHz 更宽的高频带，显著降低高频冲击与 共振成分被混叠或频谱截断的风险。因此，48kHz 的数据在时域脉冲细节与包络谱分析上 具有更高的信息保真度，有利于提取与故障相关的瞬时冲击特征与高阶谐波成分。 

（2）测点一致性与传递路径 

驱动端近轴承位置、传递路径短、振动幅值衰减小，能够更直接地反映轴承局部缺陷 激发的冲击信号。源域中 DE 的数据在传递函数与测点耦合特性上与目标域高度一致，有 助于降低测点引起的域间分布差异，从而减小源域到目标域迁移时的协变量偏移。 

（3）故障可识别性 

由于传感器位置靠近故障源，DE 信号通常具备更高的信噪比（SNR），冲击包络与 瞬态能量更明显，利于基于包络谱、峭度等统计量的弱故障检测。相比之下，FE（风扇端） 或基座（BA）信号经多层结构传递后高频成分显著衰减，且易混入结构或动力系统其它激 励（如风扇叶片频率），导致特征冗余与域差异增大，不利于迁移学习。 

（4）可处理性与后处理策略 

选择 48kHz 源数据为上游准备提供了更大的后处理灵活性：可以在保持高频信息的前 提下，通过适当的带限滤波并使用高质量的重采样将源数据下采样到目标域采样率 （32kHz），以实现采样率一致化而不丢失关键故障带信息。相比之下，直接使用 12kHz 数据将迫使丢弃高频诊断信息或进行风险更高的频谱外推，且难以通过插值恢复丢失信

#### 4.3 数据预处理 

本研究需将源域 DE 加速度信号从 48kHz 变换为与目标域一致的 32kHz，以消除采样 率差异导致的域偏差（sampling-induced domain shift），并使用 SMOTE 对数据集进行样本 平衡，以改善分类器对少数类的识别能力。变换与采样的总体流程如下： 

（1）高质量重采样：采用多相或基于窗函数/带限插值的重采样方法将 48kHz 转换到 32kHz（降采样比为 3:2），避免简单整除/插值带来的频谱畸变。 

（2）幅值归一化与传感器响应校正：对源/目标信号做统一的幅值归一化，必要时进 行传感器灵敏度或频率响应校正以减少测量链差异。 

（3）特征验证：重采样后在源域上计算典型故障特征（外圈（OR）、内圈（IR）、 滚动体（B）故障和正常状态（N）），并与原始 48kHz 结果对比，确认关键故障频率和 包络能量保留良好；若发现显著损失，调整滤波器参数或考虑保留更高原始采样用于特征 提取再进行特征级对齐。

频域特征指标是通过对振动信号进行傅里叶变换，将其由时域转换至频域后提取的一 类特征参数。该类指标能够揭示信号在频率维度上的能量分布与谱结构特征，从而为滚动 轴承故障诊断提供重要依据。常用的频域指标包括频谱均值、频谱方差、频谱峭度、频谱 偏度等统计量，分别反映频率分布的集中趋势、离散程度及谱形态特征。此外，频域能量 比、主频率及频带能量分布等指标能够刻画信号能量在不同频率区间的分布规律，对识别 故障特征频率及其倍频成分具有重要意义。相比时域分析，频域特征能够更直观地反映出 由局部损伤所引起的周期性冲击特征，因而在滚动轴承故障的特征提取与模式识别中得到 了广泛应用。

#### 4.5.3 熵域特征 

熵域特征指标是一类基于信息论与非线性动力学理论的特征量，主要用于衡量振动信 号复杂性与不确定性。在滚动轴承故障诊断中，熵类指标能够有效揭示信号的随机性、混 沌性及非平稳特征，对弱故障特征的提取具有较高敏感性。常用的熵类特征包括近似熵与 样本熵，用于刻画时间序列模式的复杂程度；排列熵则通过分析相空间重构后的符号序列 分布来反映系统动态演化特性；此外，能量熵、谱熵及模糊熵等指标能够从能量分布、频 谱特性及模糊集理论等不同角度揭示信号的不确定性。总体而言，熵域特征能够从信息量 和复杂性层面对滚动轴承运行状态进行有效表征，尤其适用于强噪声及非平稳环境下的故 障诊断。

（2）MixHop 模型原理 

MiXHop（Mixing Multiple Orders of Graph Convolutions）模型<sup>[10]</sup> 是一种图神经网络 （GNN）模型，其核心思想是在单层中同时聚合节点的多阶邻居信息。传统的图卷积网络 （GCN）通常只聚合一阶邻居的信息，而 MiXHop 通过引入多阶邻接矩阵的幂次，实现了 在同一层中同时学习一阶、二阶乃至更高阶邻居的特征。随后，这些不同阶的特征被串联 在一起，用以丰富节点表示。其基本流程如下： 

（i）输入特征：将特征矩阵 输入模型，其中 N 为窗口数，d 为特征维度。 

22 

（ii）多阶邻居扩散：利用邻接矩阵的不同幂次( )对输入特征进行传播， 

从而在同一层内同时捕获一阶、二阶及更高阶邻居的特征信息。 

（iii）特征映射与拼接：对每阶邻居特征分别进行线性变换，并在特征维度上拼接， 得到包含多阶信息的综合特征表示。 

（iv）非线性与正则化：对拼接后的结果施加非线性激活函数（如 ReLU），并结合 Dropout 等正则化方法，提升模型的表达能力与泛化性能。

Vision Transformer 处理图像的整体流程如下： 

(1)图像分块：将输入图像分割成一系列固定大小且互不重叠的 Patch，通常选择 

像素的 Patch 作为分割单位。每个这样的 Patch 随后被展平为一维向量，这样，原始图像被 转化为一个由一维向量构成的序列。其形式与自然语言中的词序列类似，使得图像数据得 以类似于文本数据的方式被模型处理。 

(2)线性投影：在将图像分割成一系列一维向量后，下一步是对这些向量执行线性投影， 即进行图像的 Token 化处理，以实现维度的变换。 

(3)类别 Token 引入：为了便于后续分类任务，ViT 在序列前添加一个额外的类别 Token （Class Token）。这个类别 Token 并非直接从输入图像中提取的特征，而是一个可学习的 参数，在模型训练过程中不断优化，以适应不同的图像数据和分类任务。 

(4)位置编码：由于 Transformer 模型无法直接处理序列的位置信息，ViT 还引入了位置 编码。通过将位置编码与 Token 序列相加，模型得以在后续的计算中充分利用每个 Token 的位置信息。 

(5)Transformer 编码器处理：结合了位置编码的 Token 序列被输入到 Transformer 的编 码器中进行处理。编码器中的多头自注意力机制负责在 Patch 之间进行全局特征提取，这 使得模型能够捕捉到图像中不同区域之间的依赖关系。同时，编码器中的前馈神经网络则 对各个 Patch 的特征进行进一步的变换和增强，从而生成更具表达力的特征表示 

(6)分类输出：从编码器最后一层输出序列中提取类别 Token 对应的表示，被用于后续 的多层感知机进行分类处理。 5.2.2 卷积神经网络 (Convolutional Neural Network, CNN)

### 8 模型的优缺点分析 

#### 8.1 模型的优点 

（1）数据预处理全面：在问题一中，先通过采样率统一、TVFEMD 与 GWO-MOMEDA 的组合降噪以及 SMOTE 样本平衡处理，最大限度提升了信号的纯净度和数据均衡性，为 后续建模提供了可靠的数据基础。 

（2）多域特征融合：构建了时域、频域与熵域的 36 项特征指标，并借助 MixHop 进 行多域特征融合，既保证了特征多样性，又增强了跨域特征的表达能力。 

（3）领域自适应策略先进：在问题三中，引入二阶与高阶统计量联合匹配，并结合 ViT 构建无监督领域自适应网络，有效缓解了源域与目标域之间的分布偏移问题，提升了跨域 诊断的可迁移性。 

8.2 模型的缺点 

（1）对极端工况的适应性有限：尽管进行了分布对齐，但在实际复杂运行环境下， 噪声干扰和样本极度稀缺仍可能导致模型性能下降。 

（2）参数依赖性强：TVFEMD 分解参数、MOMEDA 滤波参数以及 MixHop 的层数 和邻阶设定均可能显著影响结果，需通过实验精调，增加了模型调参难度。
